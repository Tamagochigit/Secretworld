# Категории каталога

Каталог в [index.html](../index.html) группирует приложения по их основной задаче. Навигация ведёт к разделам обычными ссылками: все карточки остаются доступными без JavaScript.

| Категория | Адрес | Приложение |
| --- | --- | --- |
| Досуг и открытия | `#leisure` | [Бюро других жизней](../apps/bureau-other-lives/index.html) |
| Связь и защита | `#connection` | [Бегемот](../apps/begemot/index.html) |

Название категории описывает пользу для человека, а не платформу. При двух приложениях поиск и фильтры добавят лишние элементы управления. Пересмотрите это решение, когда каталог перестанет удобно просматриваться целиком. Не создавайте пустые категории и не меняйте якорь уже опубликованного раздела без сохранения прежних ссылок.

У новой карточки должна быть отдельная страница, действующая ссылка запуска или загрузки, текущий статус и сведения о данных. Включите страницу в список `pages` в [scripts/validate_site.py](../scripts/validate_site.py), обновите счётчик на главной и проверьте мобильную ширину. Стили карточек ограничены `.catalog-group`, стили страницы Бюро — `.bureau-page` в [style.css](../style.css).

Бюро разрабатывается отдельно в [Tamagochigit/bureau-other-lives](https://github.com/Tamagochigit/bureau-other-lives). Источник сведений для карточки — версия 0.4.1 этого приложения: 20 миссий, Android 8+, локальный дневник, Telegram для общения и отсутствие автоматической синхронизации. Иконка скопирована из [исходного SVG](https://github.com/Tamagochigit/bureau-other-lives/blob/4887048d7860f25e7848a3edee9888ccb16685b1/public/icon.svg); [APK 0.4.1](https://github.com/Tamagochigit/bureau-other-lives/blob/main/downloads/bureau-0.4.1.apk) размещён в том же репозитории. Не представляйте загрузку из GitHub как публикацию в RuStore. При выходе версии сверяйте платформу, количество миссий, ссылку APK и сведения о данных с исходным проектом.

Публикация идёт штатным [GitHub Pages workflow](../.github/workflows/pages.yml); сервер и миграция не нужны. Для отката верните коммит добавления категории, сохранив прежние страницы Бегемота.
