# Невидимый бизнес · Cloudflare Workers AI

**Развёрнут:** `https://invisible-business-ai.ai-2af.workers.dev` (октябрь 2026). Сайт Secretworld уже использует этот адрес автоматически; пользователям не нужно вводить URL или API-ключ. GET `/health`, CORS preflight и реальный POST `/analyze` проверены. В пользовательском интерфейсе перед отправкой требуется согласие.

Cloudflare Workers AI заменяет Puter. GitHub Pages остаётся статическим сайтом, ИИ-запросы проходят через собственный Worker. В браузере нет API-ключей.

## Бесплатная квота
Workers Free включает до **10 000 Neurons в сутки**. GLM-4.7-Flash разрешена на Workers Free. При превышении бесплатной квоты запрос отклоняется; автоматических платных запросов в Free нет. Провайдер может изменить условия.

## Развёртывание (однократно)
1. Зарегистрировать бесплатный аккаунт Cloudflare: https://dash.cloudflare.com/sign-up
2. С компьютера с Node.js открыть директорию \`apps/invisible-business/cloudflare\` из проекта.
3. Выполнить \`npx wrangler login\` и авторизоваться в своём Cloudflare.
4. Выполнить \`npx wrangler deploy\`. Не подтверждать переход на платный Workers Plan.
5. Wrangler выведет адрес Worker в формате \`https://invisible-business-ai.<ваш-subdomain>.workers.dev\` (поддомен и доступность индивидуальны).
6. Если Worker разворачивается в другом аккаунте или по новому адресу, обновить фиксированную переменную `entry` в `apps/invisible-business/index.html`. Для уже развёрнутого Worker ввод URL на сайте не нужен. Выполнить обычный анализ отзывов и нажать **Углубить с ИИ**.
7. Для работы именно из РФ дополнительно проверить доступность сайта и Worker с устройства на российской сети. При недоступности `workers.dev` можно использовать собственный домен Cloudflare, после проверки его доступности.

Проверка Worker: открыть \`https://<адрес>/health\`. Ожидаемый ответ \`{"ok":true,...}\`.

## Защита и приватность

Не отправляйте частные, чувствительные или персональные данные третьих лиц в облачный ИИ. Бесплатная квота общая для всего аккаунта Cloudflare; публичные запросы могут её исчерпать.
- На адрес Worker передаются только выбранные пользователем отзывы (до 25 фрагментов по 330 символов), ниша и локация, **после согласия**. Пользователь сам удаляет персональные данные.
- Worker принимает запросы только с Origin \`https://tamagochigit.github.io\`. Это не полноценная аутентификация, поскольку HTTP-заголовок Origin можно подделать вне браузера.
- Ограничения: до 3 запросов в минуту на IP и 20 запросов в минуту всего по точке Cloudflare; это защита от простого злоупотребления, **не гарантия** глобального бюджета. Необходима аутентификация или Turnstile для масштабной публичной эксплуатации.
- За пределами Cloudflare сохраняется только адрес Worker в localStorage браузера. Тексты отзывов не сохраняются на сервере Secretworld.
- При отказе облачного ИИ локальный анализ остаётся работоспособным.

## Примечание
Worker успешно развёрнут с разрешения владельца Cloudflare. В реальном тесте модель GLM-4.7-Flash вернула структурированный JSON, HTTP 200. Для коротких аналитических задач отключены рассуждения через `chat_template_kwargs.enable_thinking=false`, иначе модель могла исчерпать выходной лимит до ответа. Не публикуйте секреты Cloudflare или токены в репозитории.
