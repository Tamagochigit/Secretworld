# Тайныймир · Secretworld

Публичный каталог независимых приложений. Сайт публикуется из `main` через GitHub Pages.

- Главная страница: `index.html`
- Бегемот: `apps/begemot/`
- Автоматическая публикация: `.github/workflows/pages.yml`

Новые проекты добавляются отдельными страницами в `apps/<название>/` и карточкой в каталоге. API, учёт Premium и ИИ-сервисы размещаются отдельно от GitHub Pages.
