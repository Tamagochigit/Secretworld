# Тайныймир · Secretworld

Публичный каталог независимых приложений. Сайт публикуется из `main` через GitHub Pages.

- Главная страница: `index.html`
- Бегемот: `apps/begemot/`
- Автоматическая публикация: `.github/workflows/pages.yml`
- Публичный справочник Бегемота: `apps/begemot/data/directory.json`
- Материалы УС на двух языках: `apps/begemot/data/us.json`
- Читатель материалов: `apps/begemot/us/`
- Редактор владельца: `apps/begemot/admin/`

Редактор работает как статическая GitHub Pages-страница: владелец вводит fine-grained GitHub token, ограниченный репозиторием `Tamagochigit/Secretworld` и правом `Contents: Read and write`. Токен используется только в памяти открытой вкладки, не попадает в адресную строку или сохранённые данные браузера и очищается после публикации. Коммит в `main` запускает проверку и публикацию GitHub Pages.

Каждый материал хранит русскую и английскую версии в `translations.ru` и `translations.en`. Русские `title`, `category` и `body` на верхнем уровне дублируются для совместимости с Android-приложением. `active: false` скрывает запись из сайта и APK-каталога.

Новые проекты добавляются отдельными страницами в `apps/<название>/` и карточкой в каталоге. API, учёт Premium и ИИ-сервисы размещаются отдельно от GitHub Pages.

В общий телефонный справочник добавляются только точные публичные номера, размещённые на официальных страницах организаций. Для каждой записи нужны `source` (страница-источник), `checked` (дата сверки), `country`, `trusted` и `official`. Не добавляйте личные номера и не помечайте совпадение номера как доказательство личности звонящего: caller ID может быть подменён.
